# Озвучка

`manifest.json` (version 3) описывает записанные клипы. Клипы склеены в спрайты `s/<голос>.mp3` и `s/names-<голос>.mp3`
(один файл на голос — меньше запросов, перемотка без Range через blob, работает офлайн из кэша).

- `lines[ключ]` — сегменты реплики: `{ "s": спрайт, "t": начало с, "d": длительность с }` или `{ "name": true }` (здесь звучит имя ребёнка).
  Ключ = `<голос>-<fnv1a(текст с «{имя}»)>`, см. `src/audio/voiceKey.ts`. Голоса: narrator, kid (Искорка, Ванюша, ёжик, помощник),
  female (мама, яблоня, речка, Снегурочка), low (печка), yaga, moroz.
- `names[голос][Имя]` — отрезок именного клипа. Имена из `src/audio/names.ts`; если имени нет — его произносит голос устройства.

Сейчас клипы сгенерированы Piper TTS (модель ru-irinia-medium, персонажи — сдвигом высоты). Чтобы заменить на запись актёра:
1. `npx tsx tools/voice/export-lines.ts` — список реплик (`tools/voice/lines.json`) и имён.
2. Положите mp3 отдельных клипов в `tools/voice/clips/` с теми же именами файлов (их печатает `gen.py`) или подмените `synth()`.
3. `python3 tools/voice/gen.py --only-missing` — соберёт спрайты и манифест.
